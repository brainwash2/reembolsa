# Reembolsa

B2B SaaS platform helping Chilean SME exporters recover their Export VAT (IVA Exportador) faster by automating the Formulario 3600.

## Tech Stack
- Next.js 16 (App Router)
- Supabase (PostgreSQL, Auth, RLS)
- Tailwind CSS + shadcn/ui
- Vercel

## Setup
1. Clone the repo.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add your Supabase keys.
4. Run the SQL migrations in `supabase/migrations/` in order.
5. Run `npm run dev`.
